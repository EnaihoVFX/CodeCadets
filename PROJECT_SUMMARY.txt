PROJECT OVERVIEW
================
A Chrome extension powered by Google Gemini AI that helps users learn
Scratch programming through interactive tutorials, personalized guidance,
and intelligent question-answering.

FEATURES
========
✅ Interactive Introduction to Scratch programming
✅ AI-powered step-by-step tutorials
✅ PDF tutorial upload and parsing support
✅ Intelligent Q&A system for help
✅ Beautiful, modern UI with gradient design
✅ Progress tracking with step indicators
✅ Easy navigation between tutorial steps

TECHNICAL STACK
===============
- Chrome Extension (Manifest V3)
- Google Gemini Pro AI API
- JavaScript (ES6+)
- HTML5 / CSS3
- PDF.js for PDF parsing

INSTALLATION STEPS
==================
1. Get Gemini API Key:
   → https://makersuite.google.com/app/apikey
   → Sign in with Google
   → Create API Key

2. Install Extension:
   → Open Chrome
   → Navigate to chrome://extensions/
   → Enable "Developer mode"
   → Click "Load unpacked"
   → Select this folder

3. Configure:
   → Click extension icon
   → Enter API key
   → Save

4. Start Learning!

USAGE
=====
Introduction Tab:
  - Get comprehensive introduction to Scratch
  - Perfect for beginners
  - Click "Get Detailed Introduction"

Tutorial Tab:

  - Get detailed AI responses
