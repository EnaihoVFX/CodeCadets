# Quick Start Guide

Get up and running in 2 minutes! ⚡

## Just Install & Go! (2 minutes)
1. Open Chrome
2. Go to `chrome://extensions/`
3. Enable "Developer mode" (top right)
4. Click "Load unpacked"
5. Select this folder
6. Done! 🎉 The extension is ready to use!

**Note:** The extension comes with a pre-configured API key, so kids can start learning immediately!

## Now You're Ready!

**Start Learning:**
- **New to Scratch?** → Introduction tab → "Get Detailed Introduction"
- **Ready to code?** → Tutorial tab → "Start Tutorial"
- **Have a question?** → Ask Question tab → Type and ask!

## Common Questions

**Q: Is this free?**  
A: Yes! The extension is free and the Gemini API has a generous free tier.

**Q: Do I need to be online?**  
A: Yes, the AI needs internet to respond.

**Q: Can I upload any PDF?**  
A: Yes, any Scratch-related PDF tutorial works.

**Q: Is my data safe?**  
A: Yes, everything stays on your device and goes directly to Google's API.
