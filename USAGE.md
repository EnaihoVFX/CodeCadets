# Usage Guide

## Getting Started

Once you've installed the extension and configured your API key, you're ready to start learning Scratch!

## Three Main Sections

### 📚 Introduction Tab

**When to use**: Perfect for absolute beginners who are new to Scratch.

**How to use**:
1. Open the extension popup
2. Click on the "Introduction" tab (selected by default)
3. Click the "Get Detailed Introduction" button
4. Read through the comprehensive introduction to Scratch

**What you'll learn**:
- What Scratch is and why it's great for learning
- Key concepts: sprites, blocks, scripts, backdrop
- How to get started with your first project
- What you can create with Scratch

### 🎓 Tutorial Tab

**When to use**: When you want hands-on, guided learning with step-by-step instructions.

**Two Tutorial Options**:

#### Option 1: General Scratch Tutorial
Perfect for learning the fundamentals without any prerequisites.

**How to use**:
1. Go to the "Tutorial" tab
2. Click "Start Tutorial" button
3. The AI will create a comprehensive step-by-step guide
4. Navigate through steps using "Previous Step" and "Next Step" buttons
5. Follow each step in Scratch

#### Option 2: PDF Tutorial
Best for following a specific course or book you have.

**How to use**:
1. Go to the "Tutorial" tab
2. Click "Choose PDF File" and select your tutorial PDF
3. Wait for the PDF to load (you'll see the filename)
4. Click "Start Tutorial" button
5. The AI will break down your PDF into manageable steps
6. Navigate through steps and follow along

**Tutorial Features**:
- Step counter showing your progress (e.g., "Step 3 of 10")
- Easy navigation between steps
- Detailed instructions for each step
- Can go back and review previous steps anytime

### ❓ Ask Question Tab

**When to use**: When you're stuck, confused, or want to learn something specific.

**How to use**:
1. Click on the "Ask Question" tab
2. Type your question in the text box
3. Click "Ask Question" button
4. Get an instant, detailed answer from the AI

**Example Questions**:
- "How do I make a sprite move across the screen?"
- "What's the difference between forever and repeat blocks?"
- "How can I detect when two sprites touch?"
- "How do variables work in Scratch?"
- "How do I create a game with a score?"

**Tips**:
- Be specific for better answers
- Ask follow-up questions if you need clarification
- You can ask questions at any stage of your learning

## Best Practices

### For Beginners
1. **Start with Introduction** - Get familiar with concepts first
2. **Follow a Tutorial** - Use the general tutorial to learn by doing
3. **Ask Questions** - Don't hesitate to ask when confused
4. **Practice** - Create your own projects after tutorials

### For Intermediate Learners
1. **Use PDF Tutorials** - Follow more advanced courses
2. **Ask Specific Questions** - Dive deeper into concepts
3. **Combine Learning** - Use tutorials and Q&A together

### Learning Workflow
1. Read the Introduction to understand the basics
2. Follow a Tutorial to learn hands-on
3. Ask Questions whenever you're stuck
4. Practice what you learned
5. Repeat with more advanced topics

## Tips & Tricks

### Maximizing Your Learning
- **Take Notes**: Keep a notepad handy while learning
- **Practice Immediately**: Try each concept right away
- **Be Patient**: Programming takes time to master
- **Experiment**: Don't be afraid to try variations
- **Use All Features**: Combine all three tabs for best results

### Common Scenarios

**"I don't know where to start"**
→ Use the Introduction tab first, then follow the general tutorial

**"I have a Scratch textbook/PDF"**
→ Upload it in the Tutorial tab and let the AI guide you through it

**"I'm stuck on my project"**
→ Use the Ask Question tab to get help with your specific issue

**"I want to learn something specific"**
→ Ask a targeted question in the Ask Question tab

**"I forgot how to do something"**
→ Ask the AI and you'll get a quick refresher

## Troubleshooting

**The AI isn't responding**
- Check your internet connection
- Verify your API key is correct
- Try refreshing the extension

**PDF upload isn't working**
- Ensure the PDF is not password-protected
- Try a different PDF file
- Use the general tutorial instead

**Answers aren't helpful**
- Try rephrasing your question
- Be more specific about what you need
- Break complex questions into smaller ones
