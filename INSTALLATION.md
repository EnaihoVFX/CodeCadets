# Installation Guide

## Quick Start

1. **Get Your Gemini API Key**
   - Visit [Google AI Studio](https://makersuite.google.com/app/apikey)
   - Sign in with your Google account
   - Click "Create API Key"
   - Copy your API key (you'll need it later)

2. **Install the Extension**
   - Open Google Chrome
   - Navigate to `chrome://extensions/`
   - Enable "Developer mode" (toggle in the top right corner)
   - Click "Load unpacked"
   - Select the folder containing this extension
   - The extension should now appear in your extensions list

3. **Configure the Extension**
   - Click the extension icon in your Chrome toolbar
   - Enter your Gemini API key in the popup
   - Click "Save API Key"
   - You're ready to start learning!

## Using the Extension

### Introduction Tab
- Perfect for complete beginners
- Click "Get Detailed Introduction" to learn the basics
- Covers key concepts like sprites, blocks, and scripts

### Tutorial Tab
- **General Tutorial**: Click "Start Tutorial" to begin a guided Scratch walkthrough
- **PDF Tutorial**: Upload a PDF file with Scratch instructions for personalized guidance
- Use Previous/Next buttons to navigate through steps
- Step counter shows your progress

### Ask Question Tab
- Type any Scratch-related question
- Get instant, detailed answers from the AI assistant
- Great for when you're stuck on a problem

## Troubleshooting

**PDF upload not working?**
- Ensure your PDF is not password-protected
- Try using the general tutorial instead
- Make sure you're uploading a valid PDF file

**API key issues?**
- Verify your key is correct
- Check that you have an active internet connection
- Ensure you're using the Gemini API key, not another Google API key

**Extension not loading?**
- Make sure Developer mode is enabled
- Check the console for errors (right-click extension icon > Inspect popup)
- Verify all files are in the correct folder
